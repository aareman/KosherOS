* Objective
  To create a Kosher linux laptop that can be used by developers.
* Method of Implementation
** Root user has full access to anything
   Solution, non root user
** Need docker access
   Solution, prevent docker from mounting files that belong to root
    Change ~/etc/docker/daemon.json~ and restart the docker daemon

   #+BEGIN_SRC json
   {
        "userns-remap": "container:container"
   }
   #+END_SRC

   #+BEGIN_SRC bash
   sudo service docker restart
   #+END_SRC

** Can browse anything
   Restrict dns to file lookup only instead of using a DNS service
** DNS does not protect against direct IP lookups
   Block all external IP with iptables
